
# IlliniNest frontend
This folder contains the UI for IlliniNest, a student-built UIUC housing research site. The goal is simple: compare apartments using source-backed signals instead of landlord marketing copy.
## What the website includes
- A landing page with dataset snapshot stats and current prototype coverage.
- A browse view where users:
  - pick a campus building destination
  - switch between walk and bike commute modes
  - compare apartments ranked by trust score
  - open a detailed evidence panel for any apartment
- A map view with apartment markers, school-building markers, and commute context.
- A methodology page explaining data sources, scoring inputs, and known limits.
- Light/dark mode toggle and top-level navigation (`Home`, `Browse`, `Map`, `Methodology`).
## Current prototype scope
The current demo is focused and intentionally small:
- 11 supported apartment profiles
- review highlights from Google and Reddit
- curated pricing, amenity, and commute summaries
- trust scoring shown as an explainable prototype score, not a final production model
## Tech stack
- React 18 + Vite
- TypeScript (TSX components)
- Leaflet + react-leaflet for map rendering
- Custom CSS with design tokens in `src/styles/`
## Local development
From this `frontend/` directory:
```bash path=null start=null
npm install
npm run dev
```
Production build:
```bash path=null start=null
npm run build
```
## Data used by the UI
The app reads apartment detail data from:
- `src/app/data/apartmentDetails.json`

That file is generated by the repository script:
```bash path=null start=null
python scripts/build_apartment_details.py
```
Run that command from the repository root (`atlas-mini-project/`) when upstream CSV inputs in `data/` change.
## Key frontend files
- `src/app/App.tsx`: route/state orchestration across pages.
- `src/app/components/HomePage.tsx`: landing page and dataset summary.
- `src/app/components/ComplexList.tsx`: ranked apartment list in browse mode.
- `src/app/components/ApartmentDetailPanel.tsx`: apartment-level evidence panel.
- `src/app/components/MapView.tsx`: interactive map with apartment and campus context.
- `src/app/components/MethodologyPage.tsx`: scoring and pipeline explanation.
